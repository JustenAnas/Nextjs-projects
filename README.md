# Next.js Projects

A collection of Next.js projects built while learning full-stack development.

## Projects

### Project 1 - DevDean
An event discovery platform for developers.
you can check it here 
https://devdean.vercel.app/

**Features:**
- Browse dev events (hackathons, meetups, conferences)
- Event detail pages with agenda, location, and organizer info
- Book your spot with email registration
- Similar events recommendations
- Cloudinary image uploads
- MongoDB database
- PostHog analytics

**Tech Stack:**
- Next.js 16, React 19, TypeScript
- MongoDB + Mongoose
- Cloudinary
- PostHog
- Tailwind CSS
- Shadcn/UI

### Project 2 - RideX
A full-stack ride booking platform inspired by Uber, connecting riders and drivers in real time. You can check it here https://ridex-liard-two.vercel.app/

#### Features:

- User and Partner (Driver) authentication
- Email OTP verification
- Google OAuth login
- Role-based authorization (User/Admin/Partner)
- Real-time ride booking system
- Live driver assignment
- Ride status tracking
- Driver onboarding workflow
- Pickup and destination search
- Fare estimation based on distance
- Razorpay payment integration
- Driver earnings dashboard
- Ride history management
- Socket.io real-time updates
- Cloudinary image uploads
- MongoDB database
- Responsive modern UI

#### Tech Stack:

- Next.js 15 (App Router)
- React 19
- TypeScript
- MongoDB + Mongoose
- NextAuth v5
- Redux Toolkit
- Socket.io
- Razorpay
- Cloudinary
- Leaflet / React-Leaflet
- Tailwind CSS v4
- Shadcn/UI
- Framer Motion
