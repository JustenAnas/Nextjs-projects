# Next.js Projects

A collection of Next.js projects built while learning full-stack development.

## Projects

### Project 1 - DevDean
An event discovery platform for developers.
you can check it here 
https://devdean.vercel.app/

**Features:**
- Browse dev events (hackathons, meetups, conferences)
- Event detail pages with agenda, location, and organizer info
- Book your spot with email registration
- Similar events recommendations
- Cloudinary image uploads
- MongoDB database
- PostHog analytics

**Tech Stack:**
- Next.js 16, React 19, TypeScript
- MongoDB + Mongoose
- Cloudinary
- PostHog
- Tailwind CSS
- Shadcn/UI
